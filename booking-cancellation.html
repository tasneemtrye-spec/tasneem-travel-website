سياسة الحجز والتعديل والإلغاء

يستقبل الموقع طلبات واستفسارات، ولا يعد إرسال النموذج تأكيداً لحجز أو دفعاً. تختلف قواعد التعديل والإلغاء والاسترداد بحسب شركة الطيران أو الفندق أو الناقل أو الجهة المنظمة ونوع الخدمة.

تواصل عبر البريدنموذج التواصل

تعرف على الخطوات العامة لطلب الحجز ومراجعة السعر وشروط التعديل والإلغاء والاسترداد قبل تأكيد الخدمة.

متى يصبح الحجز مؤكداً؟

  • بعد مراجعة تفاصيل الخدمة والسعر والتوافر والشروط وإبلاغ العميل بها.
  • بعد موافقة العميل واستكمال إجراءات مزود الخدمة والمتطلبات اللازمة.
  • يجب حفظ إشعار التأكيد أو التذكرة أو القسيمة الصادرة من الجهة المقدمة للخدمة.

التعديل والإلغاء

  • تخضع تذاكر الطيران لشروط السعر وشركة الطيران ورسوم التغيير والإلغاء.
  • تخضع حجوزات الفنادق والبرامج السياحية لسياسات مزوديها.
  • قد تختلف المواعيد النهائية والرسوم بحسب كل حجز.

الاسترداد

  • لا يمكن تحديد سياسة استرداد موحدة لجميع الخدمات.
  • يجب توضيح المبلغ القابل للاسترداد والرسوم والمدة المتوقعة كتابياً قبل اعتماد الحجز.
  • تتم معالجة المبالغ وفق شروط المزود وطريقة الدفع المعتمدة.

قبل الدفع

  • اطلب عرضاً مكتوباً يحدد الخدمة والسعر والضرائب والرسوم.
  • اقرأ شروط الإلغاء وعدم الحضور والتغيير.
  • لا تحول مبالغ إلى حساب غير مؤكد أو قناة غير معتمدة من الوكالة.
ملاحظة: مسودة تشغيلية: لم تقدم الوكالة بعد جدولاً معتمداً لرسوم الإلغاء أو آجال الاسترداد أو بيانات الدفع. لذلك لا تنشر هذه الصفحة نسباً أو مواعيد أو وعوداً مالية.
