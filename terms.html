شروط الاستخدام

باستخدامك للموقع أو إرسال طلب خدمة، فإنك تستخدم قناة للاستفسار والتواصل الأولي. لا ينشئ إرسال النموذج وحده عقد سفر أو حجزاً مؤكداً أو التزاماً بإصدار تذكرة أو تأشيرة.

تواصل عبر البريدنموذج التواصل

شروط عامة لاستخدام موقع تسنيم للسفريات والسياحة وطلب الخدمات والاستفسار عنها، مع توضيح حدود المعلومات والتأكيد.

المعلومات المعروضة

  • المعلومات على الموقع عامة وتعريفية وقد تتغير بحسب الوجهة والموسم ومزود الخدمة.
  • يجب مراجعة السعر والتوافر والشروط الواردة في العرض النهائي قبل الموافقة.
  • لا تعتبر صور الوجهات أو أمثلتها تأكيداً لتوافر برنامج بعينه.

طلبات الخدمات

  • يرسل المستخدم بيانات صحيحة بالقدر اللازم لفهم الاستفسار.
  • يراجع فريق الوكالة الطلب ويتواصل مع العميل عبر قناة مناسبة.
  • لا يتم تأكيد حجز أو تحصيل مبلغ من خلال مجرد إرسال النموذج.

التأشيرات والوثائق والحج والعمرة

  • قرارات التأشيرات وإصدار الوثائق والتصاريح من اختصاص الجهات الرسمية.
  • أي تنظيم لخدمات الحج والعمرة يخضع للتراخيص والاشتراطات والجهات المعتمدة في الموسم المعني.
  • لا يضمن الموقع قبول طلب أو إصدار وثيقة أو تأشيرة.

العروض والتكاليف

  • يحدد العرض المكتوب الخدمات المشمولة والأسعار والضرائب والرسوم ومواعيد الصلاحية.
  • تطبق شروط مزود الخدمة عند وجود تعارض مع المعلومات العامة بالموقع.
