# موقع تسنيم للسفريات والسياحة

هذه النسخة مبنية على فرع المراجعة المستقل، ومهيأة لمراجعة الموقع قبل اعتماد أي نشر نهائي.

## مكونات الموقع
- `index.html` الصفحة الرئيسية، وتتضمن نموذج طلب السفر.
- `admin.html` لوحة إدارة طلبات السفر.
- `privacy.html` سياسة الخصوصية.
- `assets/tasneem-official.webp` الشعار الرسمي.
- `assets/yemenia-hero.svg` رسم طائرة اليمنية المستخدم في الواجهة.
- `hero-sunset-background.jpg` أصل بصري محفوظ في المستودع؛ لا يُفترض أنه مستخدم حالياً في الواجهة.
- `index-deploy-branch-backup.html` نسخة احتياطية يجب عدم حذفها أثناء المراجعة.

## التكاملات
- نموذج الحجز يرسل الطلبات إلى Supabase Edge Function باسم `submit-booking`.
- لوحة الإدارة تستخدم Supabase Auth وقاعدة بيانات طلبات الحجز.
- بيانات التواصل الظاهرة حالياً تستخدم الرقم السعودي الرسمي: `+966 53 701 7117`.

## النشر والمراجعة
- إعداد Cloudflare Pages الحالي يستخدم جذر المستودع (`/`) وملف `index.html` كصفحة دخول.
- لا تُنشر هذه النسخة نهائياً ولا تُدمج في `main` إلا بعد إكمال اختبارات الواجهة والنموذج ولوحة الإدارة وموافقة صاحب المشروع.
- لا تضع مفاتيح سرية أو كلمات مرور في ملفات المستودع. مفتاح Supabase المنشور في الواجهة يجب أن يكون مفتاحاً عاماً فقط، مع الاعتماد على سياسات قاعدة البيانات والتحقق في الخادم.
