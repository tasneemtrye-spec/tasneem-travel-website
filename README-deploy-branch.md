# موقع تسنيم للسفريات والسياحة

هذه ملفات الموقع الجاهزة للنشر على Netlify.

## الملفات
- `index.html` الصفحة الرئيسية للموقع.
- `hero-sunset-background.jpg` خلفية الواجهة.
- `yemenia-aircraft.png` صورة الطائرة المستخدمة في تصميم الواجهة.

## النشر
يجب أن تكون هذه الملفات في جذر المستودع (Root)، بحيث يكون `index.html` ظاهراً مباشرة عند فتح المستودع. لا ترفع ملف ZIP وحده؛ فك ضغطه ثم ارفع الملفات الموجودة بداخله.
