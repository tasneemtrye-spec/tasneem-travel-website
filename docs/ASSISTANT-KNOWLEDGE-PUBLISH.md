# اعتماد ونشر قاعدة معرفة مساعد تسنيم

## مسار العمل
1. يحفظ المحرر المسودة في `public.assistant_knowledge`.
2. زر «اعتماد ونشر للمساعد» يعرض تأكيداً صريحاً قبل أي نشر.
3. قبل النشر، يتحقق من أن المحتوى المعروض يطابق المسودة المحفوظة وأن رقم الإصدار لم يتغير منذ تحميله.
4. تستدعي الواجهة دالة RPC آمنة تتحقق من الإصدار وتقفل صف المسودة ثم تنشره ذرياً إلى `public.assistant_knowledge_published`، لمنع سباق التحديثات.
5. Worker يقرأ النسخة المنشورة فقط باستخدام Supabase publishable key؛ لا يقرأ جدول المسودات ولا يستخدم service-role.
6. عند غياب إعدادات Supabase أو فشل الاتصال أو فساد المحتوى، يعود Worker إلى النسخة المضمنة المعروفة.

## إعداد Worker بعد اعتماد PR
أضف متغيري البيئة إلى Worker `tasneem-ai-assistant`:
- `SUPABASE_URL`: عنوان مشروع Supabase.
- `SUPABASE_PUBLISHABLE_KEY`: مفتاح publishable للمشروع.

لا تضف service-role key إلى Worker أو المتصفح.

## حماية النشر
- الزوار لديهم قراءة فقط لحقول المحتوى والإصدار ووقت النشر.
- لا يملك anon صلاحيات كتابة.
- لا تمنح أدوار `anon` أو `authenticated` صلاحيات مباشرة للإدراج أو التحديث أو الحذف في جدول النشر.
- لا يمكن تنفيذ الكتابة إلا عبر RPC بصلاحية `SECURITY DEFINER`، مع فحص صريح لهوية الإدارة من JWT، وقفل المسودة، ومطابقة الإصدار والتحقق من البنية قبل النشر.
- يجب أن يكون `search_path` فارغاً مع تأهيل أسماء الجداول والدوال بالمخطط لتقليل مخاطر حجب الكائنات.
- لا توجد سياسة DELETE.
- دالة `publish_assistant_knowledge(expected_version)` تعمل بصلاحية مالكها، لكنها لا تثق بالاستدعاء وحده: تتحقق من JWT الإداري، وتقفل سجل المسودة، وتتحقق من رقم الإصدار وبنية JSON، ثم تنفذ النشر ضمن معاملة واحدة. التنفيذ متاح لدور `authenticated` فقط، ولا توجد صلاحيات DML مباشرة على جدول النشر.
- لا يمكن نشر محتوى غير محفوظ أو إصدار مسودة قديم عبر الواجهة.
- المحتوى المنشور يصبح عاماً؛ يجب مراجعته قبل التأكيد.

## التحقق المطلوب
- anon يستطيع قراءة الحقول العامة فقط؛ لا يملك anon أو authenticated صلاحيات DML مباشرة على جدول النشر.
- مستخدم authenticated غير إداري لا يستطيع تنفيذ RPC؛ ولا يستطيع أي مستخدم authenticated الكتابة المباشرة في جدول النشر.
- حساب الإدارة يستطيع النشر بعد تأكيد صريح فقط، وتمنع الدالة الذرية نشر إصدار قديم أو تخطي تحديث متزامن.
- Worker يعيد `knowledge_version` المنشور، ويقرأ التحديث، ويستخدم fallback عند تعطل Supabase.
- أسئلة السعر والتأشيرة والوثائق الحساسة تظل ضمن قيود عدم الاختلاق وحماية الخصوصية.
- **حالة الإنتاج (2026-11-16):** تم إنشاء جدول `assistant_knowledge_published` وسياسة القراءة العامة المقيدة، وتفعيل RPC `publish_assistant_knowledge(expected_version)` في Supabase الإنتاجية. تم تحديث Worker `tasneem-ai-assistant` ليقرأ النسخة المنشورة عبر مفتاح publishable فقط، مع الرجوع إلى المعرفة المضمنة عند غياب سجل منشور أو تعذر الاتصال. لم يتم نشر قاعدة المعرفة إلى الزوار بعد؛ لا يحدث ذلك إلا عند حفظ المسودة ثم اعتمادها من حساب الإدارة.
